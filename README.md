# Лабораторна робота №6 — варіант 2

Код для дослідження впливу масштабу й адаптації Faster R-CNN на аерознімках контейнерів TRUDI. Репозиторій містить лише потрібні скрипти й залежності; DOCX, датасети, метрики та ваги моделей зберігаються окремо.

## Дані й модель ЛР4

Встановіть пакети з `requirements.txt`. Розмістіть [TRUDI](https://github.com/egulsoylu/trudi) у `datasets/trudi/coco/aerial/{train,val,test}/` в корені репозиторію: у кожній папці потрібні `annotations.json` і зображення.

ЛР6 стартує від вибраного checkpoint з [окремого репозиторію ЛР4](https://github.com/glebanty19/lab4-variant2-dronewaste). Скопіюйте з виконаної ЛР4 до цього репозиторію:

1. `lab4/runs/variant2_audit/selected_lr4_model.json` → `lab6/runs/variant2_audit/selected_lr4_model.json`.
2. Вибраний у JSON файл `runs/<назва_моделі>/best.pt` → `lab6/runs/<назва_моделі>/best.pt`.

## Запуск

```powershell
py -m pip install -r requirements.txt
py lab6/run_trudi_lr6.py
```

Скрипт навчає контейнерну голову, порівнює відносні масштаби ×1/×2/×4, масштабну аугментацію, донавчання й плитки з контекстом; результати створюються в `lab6/runs/`, звіт — у корені. TRUDI містить переважно вантажні контейнери; фізичний GSD кадрів у локальних COCO-анотаціях невідомий, тому ×2/×4 є емульованими змінами деталізації, а не виміряними 6/12 см.
